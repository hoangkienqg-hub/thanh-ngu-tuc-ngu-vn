🎮 Hướng Dẫn Deploy Game Để Học Sinh Chơi

❓ Vấn Đề Bạn Đang Gặp

Lỗi: "jp.zaloapp.com/invalidurl" hoặc "Website can't be reached"
Nguyên nhân: Bạn đang thử mở file từ máy tính (file://) hoặc link không hợp lệ

✅ Cách 1: Dùng Netlify Drop (NHANH NHẤT - 2 PHÚT)

1 Truy cập: Mở Netlify Drop
2 Kéo thả thư mục thanh-ngu-tuc-ngu vào khung hiển thị
3 Chờ vài giây → Netlify tự động tạo link
✅ Hoàn thành! Link sẽ có dạng:
https://random-name-123456.netlify.app

Hướng dẫn cho học sinh:
Gửi link này qua Zalo → Học sinh bấm vào → Chơi được ngay!

✅ Cách 2: Dùng GitHub Pages (MIỄN PHÍ VĨNH VIỄN)

1 Tạo tài khoản GitHub: GitHub.com
2 Tạo repository mới (tên gì cũng được, ví dụ: thanh-ngu-game)
3 Upload toàn bộ thư mục thanh-ngu-tuc-ngu lên repository
4 Vào Settings → Pages → Chọn main branch → Save
✅ Hoàn thành! Link sẽ là:
https://tencuaban.github.io/thanh-ngu-game/

⚠️ KHÔNG Làm Những Việc Sau

❌ Hành Động ⚠️ Hậu Quả
Gửi link file:///D:/... Học sinh không mở được (chỉ chạy trên máy của bạn)
Upload lên Google Drive rồi chia sẻ link Google Drive chặn chạy HTML local
Open bằng trình duyệt từ thanh địa chỉ Phải duyệt đến đúng file .html

📱 Test Trước Khi Gửi Cho Học Sinh

1 Mở link trên điện thoại (không phải máy tính)
2 Kiểm tra:
  • □ Giao diện hiển thị đẹp
  • □ Nhập tên được
  • □ Nhấn nút "Bắt Đầu" được
  • □ Chọn đáp án được
  • □ Hiển thị điểm số
3 Nếu mọi thứ OK → Gửi link cho học sinh qua Zalo!

💡 Mẹo: Lưu Link Dễ Nhớ

Dùng dịch vụ rút gọn link để học sinh dễ nhớ:

  • Bitly.com
  • TinyURL.com
  • VN.LY (của VNG)

Ví dụ: https://vn.ly/3xYzAbc thay vì https://abc123.netlify.app/games/.../game_standalone.html

🆘 Vẫn Còn Lỗi?

Nếu vẫn gặp vấn đề, hãy:

  1. Chụp màn hình lỗi
  2. Mở Console (F12) → tab Console
  3. Chụp ảnh các dòng chữ đỏ (lỗi)
  4. Gửi lại cho tôi để hỗ trợ
